    Utiliser la voix dans Discord, OBS ou un jeu
    1. Installez un câble audio virtuel gratuit, par exemple VB-CABLE (vb-audio.com). Il crée deux appareils : « CABLE Input » et « CABLE Output ».
    2. Ici, choisissez CABLE Input comme sortie virtuelle. Voix Studio le détecte tout seul quand il est installé.
    3. Dans Discord, OBS ou votre jeu, choisissez CABLE Output comme micro.
    4. Laissez cette fenêtre ouverte : la transformation s’arrête si vous la fermez. Elle peut rester en arrière-plan.
